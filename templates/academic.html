Section 8.2 Mathematical Formulation: Behaviour Drift Score

Implemented strictly according to the student proposal specifications

Formula Breakdown:
DNS Drift: D_DNS = max(0, (Observed_DNS - Baseline_DNS) / Baseline_DNS)
IP Drift: D_IP = max(0, (Observed_IP - Baseline_IP) / Baseline_IP)
Port Drift: D_Port = max(0, (Observed_Port - Baseline_Port) / Baseline_Port)
Volume Drift: D_Vol = max(0, (Observed_Bytes - Baseline_Bytes) / Baseline_Bytes)
Combined Behaviour Drift Score = (w1 * D_DNS + w2 * D_IP + w3 * D_Port + w4 * D_Vol) / (w1 + w2 + w3 + w4)
Proposal Worked Example (Laptop 04 Data Exfiltration & Port Scan):
DNS Requests 300 vs 40 +650%
Remote IPs 85 vs 12 +608%
Ports Contacted 42 vs 5 +740%
Data Transferred 900MB vs 50MB +1700%
Proposal example: The worked values produce a high composite drift score. The application calculates risk separately from triggered indicators; only the combined risk score can trigger a quarantine decision.
